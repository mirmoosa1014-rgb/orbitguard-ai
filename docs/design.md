## Structure and tokens

The app opens directly on a technical drawing, without a promotional hero or metric-card row. A dominant 3D wireframe ephemeris occupies the sheet; a narrow instrument rail holds replay, measurement, time-index and projection tools. A separate encounter register exposes the real catalog. Relative separation, maneuver proposals and sensor residuals occupy drawing panels below. A squared title block records drawing number, reference frame, model and validation readouts.

| Source token or primitive | Scientific adaptation |
| --- | --- |
| `bg #071E36`, fine cyan grid | Navy drafting sheet; coordinate construction grid does not represent terrain or data. |
| `primary #7FDBFF` | Numerical protected trajectory and construction strokes. |
| `ink #E5F6FF`, `textDim #8FB4C9` | Selected-object dashed path and secondary catalog/residual traces; line styles preserve distinctions without relying on color alone. |
| `secondary #F2C14E` | Radius dimension, measured time and separation readouts and Pareto dimension markers. No yellow decorative fills. |
| Helvetica Neue / 500 / .140em / uppercase | Instrument title. |
| Helvetica Neue / 400 / .040em | Explanations and limits. |
| SF Mono / 500 / .080em / uppercase | Title block, object register, drawing annotations and controls. |
| Sheet, PlanStroke, Dimension, Leader | Square closed-path drawing outline, 3D wireframe Earth/orbits, true radius extension lines, elbow callout for protected spacecraft. |

No glow, blur, gradients, rounded cards, springs, AI pills or semantic traffic-light colors. Orbital canvas and generated analysis figures/GIF share the source palette. Solid fills are restricted to navy paper and low-opacity covariance regions; uncertainty values and plot scales are unchanged.

## Clip mapping

| Clip | Duration and easing | Application |
| --- | --- | --- |
| `stroke_draw` | 1.05 s; cubic-bezier(.65,0,.35,1) | Closed frame drawn as one SVG path; finite canvas stroke construction and data-trace entrance. Canvas evaluates the same cubic-bezier curve, not a spring approximation. |
| `tick_in` | .2 s; cubic-bezier(.16,1,.3,1) | Measurement ticks and markers follow completed paths at 1.05 s. |
| `label_in` | .35 s; cubic-bezier(.16,1,.3,1) | Labels and dimensions follow ticks at 1.25 s. |
| Repeated element stagger | .04 s | Secondary plot stroke entrance. |

The library’s perpetual idle suggestion is deliberately omitted for scientific readout stability. Initial simulation time is paused at the actual recorded t=0; decorative entrance never changes frame/time/readout values. Replay remains available as an explicit instrument action and advances the same recorded frames at the same cadence as before. An object selection or projection change does not invent a data transition or interpolate the displayed measurements.

`prefers-reduced-motion: reduce` presents completed geometry and labels immediately, disables entrance CSS, and leaves time paused. Manual time scrubbing, selection and 3D transforms remain functional. A media-preference change pauses replay; a user can explicitly request replay afterward.
