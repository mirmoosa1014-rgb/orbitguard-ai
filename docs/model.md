# Model card

Small NumPy logistic regression, 4 features, L2 regularization .005, 1600 fixed training iterations, class-balanced objective; JSON weights/scales, no pickle. Features: initial coarse closest separation (km), relative speed (km/s), time of coarse closest approach / horizon, and initial position uncertainty (km). The last is constant .3 in this version and offers no useful discrimination.

Data is generated by the RK4 simulator. Seeds 100–129 (family 1, radius 6839 km, inclination .205 rad) train the model; seeds 400–404 (family 4, radius 6893 km, inclination .370 rad) fit Platt calibration and tune CV process noise; seeds 700–714 (family 7, radius 6947 km, inclination .535 rad) are untouched until evaluation. Whole catalogs, not adjacent timesteps, are split. The seed-2026 UI is separate from scored test data. Standardization uses training only.

Training labels indicate sampled true separation below the illustrative 10 km refinement threshold. No operational collision probabilities are estimated. Validation-only calibration reduces class-balancing distortion but remains imperfect under distribution shift. Use raw scores only for ranking; calibration is evaluated separately. Fixed training configuration, no test-set tuning.

`rank_candidates` returns coarse-distance ordering when the trusted bundled JSON model is missing, malformed, schema-incompatible or produces nonfinite values. No user-uploaded serialized model is accepted. Inference and fallback are tested. Learned recall loses to coarse distance in this experiment; no claim of useful operational ML follows.
